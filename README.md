# GetPlaced — No-Nonsense DSA & Placement Prep Tracker

> **GetPlaced** is an all-in-one placement preparation platform engineered for students grinding for technical interviews. It tracks progress across trusted, curated problem sheets with instant search, auto-saved local progress, and zero fluff.

---

## ⚡ Highlights

- **Track Your Grind**: Local, client-side auto-saving of solved checkmarks, starred questions, and personal revision notes.
- **Curated DSA Sheets**:
  - **Striver's A2Z DSA Sheet** (455 Problems)
  - **Love Babbar DSA Sheet** (430 Problems)
  - **NeetCode 150 Sheet** (150 Problems)
  - **Rohit Negi (Coder Army)** (726 Problems)
  - **Shradha Khapra (Apna College)** (403 Problems)
  - **Fraz DSA Sheet** (279 Problems)
  - **Arsh Goyal DSA Sheet** (287 Problems)
- **20 Core Algorithmic Patterns**: Pattern-first problem solving covering Sliding Window, Two Pointers, Fast & Slow, Intervals, Monotonic Queues, and more.
- **Company-Wise Question Banks**: Direct assessment and onsite question banks across 45+ premier tech firms (Google, Meta, Microsoft, Amazon, Uber, DE Shaw, Flipkart, etc.).
- **Top 110 SQL Interview Sheet**: Interactive questions with syntax-highlighted solutions and 1-click copy.
- **System Design Blueprints**: 32 High-Level (HLD) and Low-Level Design (LLD) architecture breakdowns.
- **Placement Toolkit**:
  - 100 Behavioral HR questions with winning STAR frameworks.
  - 25 Cold Outreach email templates for referrals and recruiter reachouts.
  - Curated CS Core subject playlists & notes (OS, DBMS, Computer Networks, OOPs).
  - ATS-friendly LaTeX & Google Doc resume templates.
- **Global Spotlight Search (`Ctrl + K` / `Cmd + K`)**: Instant search across 2,500+ problems, SQL queries, and company questions.
- **Daily Streak Heatmap**: GitHub-style activity calendar to keep you consistent every day.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State & Storage**: Pure Client-Side React Context + LocalStorage with JSON Export/Import

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ankurosaurus/getplaced.git
cd getplaced

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
